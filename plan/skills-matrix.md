# 技能矩阵

> 用这张表追踪你在 Agent 开发各技术栈上的熟练度。
>
> 等级定义：
> - **0 — 不了解**：没听过或只是听说过名字
> - **1 — 了解概念**：能说清楚是什么、大概怎么用
> - **2 — 动手用过**：跟着教程写过 demo
> - **3 — 能独立开发**：不看文档可以写出一个功能
> - **4 — 能讲清楚原理**：面试水平，能讲"为什么"和"底层怎么实现"
> - **5 — 能设计系统**：可做架构决策、选型和权衡
